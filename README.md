# goit-js-hw-02

Homework assignment for GoIT JavaScript course. Topic 2: Conditionals and Loops.
Домашнє завдання курсу JavaScript від GoIT. Тема 2: Розгалуження та цикли.

## Tasks / Завдання

- **Task 1** — `makeTransaction(quantity, pricePerDroid, customerCredits)`: checks if customer has enough credits and returns order message or "Insufficient funds!" / перевіряє баланс клієнта і повертає повідомлення про замовлення або відмову
- **Task 2** — `formatMessage(message, maxLength)`: truncates a string to maxLength and adds "..." if it exceeds the limit / обрізає рядок до maxLength символів і додає "..." якщо перевищує ліміт
- **Task 3** — `checkForSpam(message)`: checks if a message contains forbidden words "spam" or "sale" (case-insensitive) / перевіряє наявність заборонених слів "spam" або "sale" незалежно від регістру
- **Task 4** — `getShippingCost(country)`: returns shipping cost to a given country using switch statement / повертає вартість доставки до вказаної країни за допомогою switch
